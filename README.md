# Black Ink Studio — MVP demonstrativo

- `index.html`: MVP navegável em um único arquivo (abra no navegador). Dados e imagens fictícios.
- `src/data/`: dados mockados tipados em TypeScript, prontos para trocar por dados da API.

As imagens do MVP são SVGs gerados no próprio HTML. Nos arquivos `.ts`, os caminhos
`/images/demo/...` são referências: coloque as imagens correspondentes em `public/images/demo/`.
